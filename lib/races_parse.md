Flutter проект: экран Profile -> Upcoming Races

========================================================
ЦЕЛЬ
========================================================

Реализовать функционал выбора гонки через BottomSheet с использованием API /api/v1/races и локальной фильтрации.

========================================================
ФУНКЦИОНАЛ
========================================================

1️⃣ Экран:

- Экран Profile -> Upcoming Races
- Убрать существующий блок добавления гонки (старый ввод вручную)
- При нажатии на кнопку "Добавить" всплывает BottomSheet с выбором гонки

2️⃣ BottomSheet:

- Отправлять GET /api/v1/races при открытии BottomSheet
- Заголовки: Authorization: Bearer {token}
- Поддерживать query параметры при необходимости, но по умолчанию получать все активные гонки
- Список гонок в формате:
    [Флаг страны] Локация, Тип гонки, Дата
- Флаг страны использовать из пакета country_flags
- Поиск:
    - Внизу или сверху поле поиска
    - При вводе фильтровать уже полученный список локально
- Выбор:
    - При тапе на элемент списка он выделяется бордером цвета ironmanRed из файла app_colors.dart
    - Можно выбрать только одну гонку
- Кнопка "Сохранить":
    - Активна только если выбран элемент
    - При нажатии отправлять выбранную гонку на сервер (создание UpcomingRace)
    - Если гонка не выбрана, кнопка неактивна

3️⃣ UI / UX:

- Список гонок должен быть scrollable
- Элементы должны четко разделяться, удобная зона тапов
- Бордер выделения должен быть заметный, цвет ironmanRed
- BottomSheet закрывается при успешном сохранении
- Ошибки сети и пустые результаты показывать через SnackBar или другой user-friendly виджет

4️⃣ Формат данных гонки из API:

{
  "id": 1,
  "date": "2026-06-14",
  "location": "Hamburg",
  "type": "ironman",
  "type_label": "Ironman",
  "country_iso": "DE"
}

- Использовать эти данные для отображения в списке
- date отображать в формате DD.MM.YYYY или в локальном формате приложения
- type_label использовать для отображения типа гонки

5️⃣ Логика сохранения:

- После выбора гонки и нажатия "Сохранить" создавать запись upcoming_race на сервере
- Должна учитываться уникальность user_profile_id + race_id
- После успешного сохранения обновлять локальный список UpcomingRaces на экране
