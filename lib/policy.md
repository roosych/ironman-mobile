У меня есть API для политик конфиденциальности, условий и обработки данных:

API Endpoints:

GET /api/v1/policies/types — получение доступных типов политик

GET /api/v1/policies/languages — получение доступных языков

GET /api/v1/policies/{type} — получение политики по типу (privacy, terms, data_processing, cookies)

Поддерживаемые языки: en, ru, az

Пример запроса на Flutter:

GET /api/v1/policies/privacy
Headers: Accept-Language: az


Или можно явно указать язык:

GET /api/v1/policies/privacy?locale=az


Формат ответа:

{
  "success": true,
  "data": {
    "id": 2,
    "type": "privacy",
    "type_name": "Privacy Policy",
    "language": "az",
    "title": "Məxfilik Siyasəti",
    "content": "<h1>Məxfilik Siyasəti</h1><p>...</p>",
    "is_active": true,
    "effective_date": "2026-02-17T07:40:18.000000Z",
    "created_at": "2026-02-17T07:40:18.000000Z",
    "updated_at": "2026-02-17T07:40:18.000000Z"
  }
}


Требуется реализовать на Flutter:

Экран PolicyScreen с аппбаром и кнопкой назад.

Белый фон, прокручиваемый текст (scrollable).

Возможность выбирать тип политики (например через Tabs или Dropdown) и язык.

Подгружать текст политики через API с учётом локали приложения.

Поддержка HTML в тексте (через flutter_html или аналог).

Если success=false или политика не найдена, показывать текст "Политика недоступна".

При загрузке показывать CircularProgressIndicator.

Обработать ошибки сети и показать пользователю сообщение "Не удалось загрузить политику".

Код должен быть чистым, с null-safety, использовать современный Flutter (>=3.0).

Использовать Provider/Notifier или Riverpod для управления состоянием.

Дополнительно для экрана Регистрация:

Добавить чекбокс с текстом: "Я согласен с Политикой конфиденциальности".

Слово "Политикой конфиденциальности" сделать ссылкой на экран PolicyScreen.

Пока не прикреплять состояние чекбокса к API регистрации — просто UI.
